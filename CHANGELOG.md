## [0.1.0]

### Added

- Interactive CLI for launching vLLM model servers on GCP through SkyPilot.
- Commands to check cloud authentication, list deployments, connect over SSH, and tear down clusters.
- Versioned model recipes, launch previews, spot capacity, and idle teardown options.
- `iwant --version` to show the installed package version.
- GitHub Releases with changelog notes and an installer pinned to each release tag.
